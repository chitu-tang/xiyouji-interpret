# 《西游记》原文片段逐段深读 Skill

v2.2（2026-10-02 发布）。核验原文，按叙事功能切段，从文字内部发现问题，做必要的定向研究，产出有主轴、有证据、有边界的中文解读稿。

## 它做什么

处理一段已经贴出的《西游记》原文，让读者看清文字具体写了什么、为什么这样写、这一处怎样推动人物或叙事，以及哪些解释只是有根据的推测。

两种运行模式：

- **直接深读（默认）**：一次交付一篇可直接评价的解读稿。默认中文口播风格，短片段约 800-1500 字，信息密集片段约 1500-3000 字。
- **策划角度**：你只问“值不值得讲”“有哪些角度”时启用。输出 2-3 个候选角度，每个绑定原文锚点、核心问题、证据可得性、解释风险和适合体裁；选定后交付 brief 或直接成稿。

## 怎么用

| 你说 | 它做 |
|---|---|
| 帮我解读 / 逐段分析 / 深度解读 / 写成口播稿 | 直接出一版片段深读 |
| 值不值得讲 / 有哪些角度 | 出策划卡，等你选 |
| 按推荐角度写 / 指定某角度写 | 按该角度成稿，不重复出菜单 |
| 第X回 / 这一回拆几篇 / 写 5000 到 7000 字长文 | 转交完整回目长文管线 |

指定完整回目长文时，本 Skill 不硬接，转交给 [xiyouji-chapter-longform](https://github.com/chitu-tang/xiyouji-deep-read)（回目核验、拆篇、研究、5000-7000 字长文、审核、归档的完整管线）。

## 引语纪律

直接引文必须与来源逐字一致，节引按句读单位标省略号，自己的概括、概念标签和章节标题不放进引号。交稿前做机械式引号扫描：逐处列出引号内文本与来源比对，未命中项改写或删去。用户消息里的原话与原文同等保护。

## 文件结构

- `SKILL.md`：主规范（分流、执行流程、11 道质量门、输出合同）
- `history.md`：策划台账，已策划条目用于角度去重与创作交接
- `references/`：角度清单、输出模板、风格指南、禁用词、AI 味检查清单
- `examples/`：回归样例。每次修改 Skill 后至少用两个结构不同的样例回归，低于 90 分、任一硬门失败或触发红线，保留失败输出，先改规则再重跑

## 边界

不把片段强行扩写成完整回目，不因存在可研究背景就越过用户提供的文本范围，不凭记忆补写原文。在线搜索与 OCR 只作定位线索，直接引文必须来自可核验文本。
