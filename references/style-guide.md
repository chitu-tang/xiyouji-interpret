# 口播稿风格指南

> 从五篇范本提炼。生成口播稿时严格遵循本文件。用户可随时要求更新。

## 一、语气定位

**大学者做公共讲座**——学问极深，说话像跟朋友聊天。

- 不端着，不装，但每一句都有东西。
- 幽默是自然溢出的，不是刻意搞笑。讲着讲着忍不住损一句（"猴哥诞生于中华文明的轴心时代""别挡哥的路，哥要去印度"），损完继续讲正事。
- 对读者/观众有平视的尊重：不居高临下教导，不刻意讨好。
- 说理时用"我们"代替"你"，拉近距离但不指教。
- 承认观众已知，不把观众当白纸。"相信大家都知道""很多都会认为"——先确认共识，再往前推一步，推翻表面共识（"那是结果导向论"）。

## 二、结构模式

### 开头

结构：**钩子 → 固定开场白**，顺序不能反。

**① 钩子**（每篇必须有，放在最前面）：

用用户原文中的具体场景、对话、诗词直接把观众拉进现场。不解释，不铺垫，让原文自己说话。钩子可以是：
- 直接念一段原文（场景描写、人物对话、诗词）
- 用一个具体细节切入（"第一回，众猴发现瀑布，立了个规矩……"）
- 从一个常见误解切入（"很多人以为……其实……"）
- 从观众已知出发（"孙悟空怎么当上美猴王的，大家都知道……"），先确认共识，然后用"那是结果导向论"推翻表面共识
- 直接抛出核心问题（"为什么是 XXX，不是 YYY？"）

钩子要短，3-5 句话把场景立住就够。每次选一种方式，不连续两篇用同一种。

**② 固定开场白**（紧跟钩子之后，一字不改）：

> 你好，朋友。今天我们来聊 XXX。

XXX 替换为本期主题（如"石猴跳瀑布这一段里，藏着的两个字""唐僧为什么和玄奘不一样"）。

开场白之后直接进入正文解读。

**禁止**：
- "有没有过这样的时刻？"等设问开头
- "最让我停下来想的一章"等读后感式表述
- 钩子超过 5 句话
- 把固定开场白放在钩子之前

### 主体

- 用清晰的小标题切分板块（如"猴王出世的地点""猴王出世的时间""猴王出世的心路"）。
- 每个板块内部的节奏：**抛问题 → 引材料 → 拆解 → 延伸到意想不到的地方 → 收回来**。
- 在适当位置直接问"为什么作者要这么写呢？"——这是从故事内部跳到外部视角的枢轴。前半段拆解文本，后半段把文本放到历史坐标系里看。
- 板块之间有过渡，但过渡要自然，不用"接下来我们看看""下面进入第二部分"这类机械衔接。

### 结尾

干脆利落，不总结，不升华，不喊口号。

可用的收束模式（在固定结束语之前）：
- 预告下期内容。
- 留一个悬念 / 问题，不回答。
- 一句话点睛，不多说。
- 双重视角收束："这是在写X，也是在写Y。"（从故事表层跳到普遍意义，一句话，不展开）。

**固定结束语**（每篇必须有，一字不改，放在全篇最后一句）：

> 好，今天我们就聊到这里。

**禁止**：
- "下次……""问自己……"等固定句式连续使用
- 任何总结性段落（"今天我们讲了三个要点……"）
- 结束语之后再加任何内容

## 三、核心手法

### 0. 自我质疑

不预设答案，边写边追问。可以在一句话里完成自我质疑：

> 这种拜王的方式有没有问题，有，一群猴子选王，不应该是战力值最高的那位才对吗？

这不是设问，是真的在审视自己刚说的话。观众听到的不是结论，是一个人在思考的过程。

### 0-b. 结构化枚举的陷阱

不要用"第一层 / 第二层 / 第三层"或"首先 / 其次 / 最后"来组织分析。一旦出现序数词，口播稿立刻变成讲稿。

改用自然的递进：上一个点讲完，用"再有……""另外……""还不止……"自然过渡。最好的情况是连过渡词都不用，靠逻辑本身推进。

### 1. 两种结构驱动（根据内容选择）

口播稿的结构不是"念原文→解释原文"。有两种有效的驱动方式，根据内容选择：

**A. 问题链驱动**：从一个核心问题出发，层层追问。每个小节回答一个问题，自然引出下一个。

> 为什么一定要"寻个源头"？→ 为什么是"源头"不是"洞里有什么"？→ "我进去"为什么连说两遍？→ 水帘洞真正考验的是什么？

适合：原文里藏着一个反直觉的细节，需要层层剥开。可以用小标题切分。

**B. 论点驱动（立误解→推翻）**：先立一个常见误解，然后一层层推翻，最后翻到更大的格局。

> "勇气使然。那是结果导向论。" → 不只是胆量，还有判断力、行动力 → 还有"不伤身体"的附加条件 → "拜"字是主动让渡权力 → 为什么作者要这么写？→ 明代出身论 vs 花果山的能力论 → "这是在写猴群选王，也是在写百姓心中的选王。"

适合：一段看似简单的情节，背后藏着作者对权力、秩序、人性的思考。不用小标题，连续说下来，过渡靠"所以""再有""另外""为什么作者要这么写呢？"

**共同原则**：观众跟着你的思路走，不是跟着原文走。原文是证据，不是脚本。

### 2. 原文是证据，不是脚本（可以零引用）

原文的角色是**支撑论点的素材**，用到才引，不是逐句拆解的对象。

- 需要引的时候，引一两句关键原文，然后立刻用自己的话展开分析。
- **完全可以一句原文都不引**。如果观众已经知道故事，直接复述："大家约定谁敢跳进水的源头里，就拜谁为王。"——这是复述，不是引用，但观众完全听得懂。
- 钩子也可以用复述代替引用："孙悟空当年是怎么当上美猴王的，相信大家都知道，就是做了别的猴子不敢做的事儿，跳水帘洞。"
- **绝对不要**按原文顺序逐句念、逐句翻译、逐句解释。那是语文课，不是解读。
- 长稿（10-15分钟）可以引原文关键句，短稿（3-5分钟）优先复述，少引或不引。

### 3. 语气有判断、有立场

不是中立分析，是有态度的讲述。该下判断就下判断，该否定就否定。

> "那是结果导向论。"
> "有没有问题，有。"
> "这不是莽夫能完成的事。"
> "花果山的猴群们，不信这一套。"

不要怕得罪人，不要怕说错。观众听的是一个有主见的人在聊天，不是一篇平衡报道。

### 4. 历史背景用画面带出，不用学者背书

不说"明代社会等级森严"，说：

> 你是官宦子弟，生下来就高人一等。你是泥腿子，一辈子就得弯腰。

用"你"把观众拉进历史现场。两句话比一段学术论述有力十倍。

学者点名仍然可以用（见下方第 6 条），但短稿里优先用画面，不用学者。

### 5. 生活类比自然嵌入

从原文的道理跳到 everyday 的生活经验，四五行收住，不展开。

> 这就像我们看见一条河。普通人会说，这水真清，这河真宽。真正要治理一方的人，会继续问，这条河从哪里来，流到哪里去，什么时候涨，什么时候枯。

类比的作用是让观众"啊，我懂了"，不是展示博学。一个类比讲透一个道理，马上收回来。

此外，拆解原文关键句时，**优先用故事世界内部的逻辑去解释**。如"不伤身体者"→ 要么有神通、要么有智慧、要么有大运。不要用现代管理术语（如"风险管控""附加条款"），穿越感会破坏沉浸。

### 6. 跨域联想

从一个点跳到意想不到的地方，再跳回来。

> "五百年"→ 孟子 → 司马谈 → "五百年前是一家" → "中华文明五千年" → 回到孙悟空

联想不是漫无目的的，每次跳跃都要有逻辑连接，最后要收回到原文。3-5 分钟的短稿里，跨域联想最多用一次，点到即止。

### 7. 学者点名（长稿用，短稿慎用）

鲁迅、胡适、季羡林、陈寅恪、钱钟书、孟子、王阳明……不是掉书袋，是"这个人说过这个话，有意思"。

- 点名时说清楚这个人是谁（一句话定位），然后引他的观点。
- 可以同意，可以反对，可以调侃。
- 3-5 分钟的短稿里，最多点一个学者，或者不点。短稿靠问题链和生活类比就够了。

### 8. 数字 / 名物考据（长稿用）

看似枯燥的考据，讲出故事来。数字不是数字，是文化密码。

> 三丈六尺五寸高 → 周天三百六十五度 → 这块石头象征天地

## 三-b、反模式（绝对不能出现的写法）

| 反模式 | 为什么不行 | 应该怎么做 |
|--------|-----------|------------|
| 按原文顺序逐句念、逐句翻译 | 变成语文课，不是解读 | 用问题链组织，原文只做证据 |
| 每个细节都问"为什么" | 变成强行解释，没有重点 | 一篇只追一个核心问题，最多 3-4 层追问 |
| 引完原文后说"这句话的意思是……" | 像教科书注释 | 用自己的话重新讲，把原文揉进分析里 |
| 每个小节都是"原文→翻译→延伸"三段式 | 模板感，机械 | 小节结构随内容变化，有的只有一句话，有的用类比，有的用追问 |
| 短稿里塞学者、塞考据、塞跨域联想 | 信息过载，没有呼吸感 | 短稿靠问题链 + 生活类比，一个点讲透就够 |
| 结尾总结"今天我们讲了……" | 像上课 | 落在一个画面或一句点睛上，然后"好，今天我们就聊到这里。" |
| 结构化枚举"第一/第二/第三" | 像讲稿，不像聊天 | 用"再有""另外"或干脆不用过渡词，让逻辑自然推进 |
| 用现代管理术语解释古典文本 | 穿越感太重，破坏沉浸 | 优先用故事世界内部的逻辑解释（神通/智慧/大运，而非"风险管控"） |

## 四、句式与节奏

- **短句为主**，口语节奏，像在说话不在写文章。
- 适当使用北方口语标志词（"这事儿""就是……的事儿""你看"），让口播稿有鲜明的口语质感，不是通用书面语的转写。
- 少用破折号（口语里用多了像在写不在说），改用逗号、句号断开。
- 少用冒号，直接用句号断句更口语。
- 少用"但 / 但是"，每 1000 字最多 1 个，用"不过""然而""却"或直接去掉。
- 不用"不是……而是……""不是……是……""不在于……而在于……"双子星句式，改用递进式。
- 不用感叹号堆情绪。
- 不用"里面藏着……""这里值得停一下……""这句话让我想了好久……"等 AI 味表达。

## 五、多样性要求

以下元素**每篇必须变化**，不能形成模板感：

| 元素 | 要求 |
|------|------|
| 开头方式 | 每篇不同（见上方开头模式） |
| 结尾方式 | 每篇不同（见上方结尾模式） |
| 板块数量和命名 | 随内容定，不固定"三段式" |
| 过渡句 | 每篇换一种方式让读者点头，不重复"这个XX太正常了"等句式 |
| 联想路径 | 每篇的跨域跳跃方向不同 |
| 幽默的位置和方式 | 不固定在某个位置，不重复同一种损法 |

## 六、原文引用策略

1. **只引关键句**，不全引。一段原文里挑最能说明问题的 1-3 句。
2. 引完**立刻**用大白话翻译 / 拆解，不留空白。
3. 如果没必要引原文，直接用自己的话复述。
4. 可以用"原文放在视频下方，有兴趣可以读一读"来省略大段引用——既省口播篇幅，又给观众互动理由。
5. 引用时注明出处（第几回、回目名），增加可信度。

## 七、解读边界（最重要）

用户发来的文本是"文本"，其他一切是"背景"。口播稿的主线必须始终围绕用户发来的这段文本展开。

- 外部知识（学术考证、宗教义理、故事蓝本、跨域联想）的作用是**照亮这段文本**，不是替代它。每一次延伸之后必须收回到原文的具体字句。
- 不得用大段篇幅解读用户未发来的其他回目、其他情节、其他人物。如果某个背景知识必须交代，用一两句话带过，然后立刻回到用户文本。
- 跨域联想的起点和终点都必须是用户文本中的具体字词。中间可以跳到孟子、跳到印度、跳到明代心学，但跳出去是为了把用户文本里的那个词讲透，不是为了讲孟子、讲印度、讲心学。
- **自检方法**：删掉口播稿中所有直接引用/提及用户原文的句子，如果剩下的内容仍然构成一篇完整的解读，说明跑偏了——背景知识喧宾夺主了。
