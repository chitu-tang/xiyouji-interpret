# 《西游记》原文片段解读输出模板

> 默认用于直接深读模式。标题、平台文案和分发素材只有在用户明确要求时追加，不是必交付物。多逻辑单元输入默认不附实质全文，只在分析中选择必要短引；极短文本或用户明确要求展示全文时例外。

```markdown
# {片段主题}

> 原文出处：{回目/版本；无法确认时如实标注}
> 分析范围：{用户提供的范围}
> 解读主轴：{一句话}
> 核验状态：{已确认 / 部分确认 / 待核}

## 解读边界
{用两三句话说明哪些是文本事实，哪些是解释；必要时列出未扩展的前后文}

## 逐段解读

### {逻辑单元 1 的短标题}
{从具体字词、动作或叙述顺序切入，展开观察、解释、证据和边界}

### {逻辑单元 2 的短标题}
{不要机械重复“原文—翻译—意义”；让本段推进主轴}

## 收束
{回到原文的字、动作或画面，不写泛泛总结}

## 研究与核验说明
- {R编号}: {来源、材料角色、支持的原文锚点、使用边界}
- 待核：{没有就写“无”}
```

## 口播稿附加规则

用户明确要求口播稿时，才追加标题、开场、结束语和平台文案。正文读取 `style-guide.md`、`forbidden.md` 与 `ai-pattern-checklist.md`；平台包装仍按用户要求单独生成。
