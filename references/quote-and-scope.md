# 范围锁、引文保真与边界校准细则

> 本文件承接 `SKILL.md` 的核心铁律，在执行 P0 核验、P4 框架设计、P5 成稿、P6 二审以及 A 模式直出时按需查阅。

## 一、范围锁与知识延展边界（最高优先级）

用户贴出的那段文字是本次任务的**核心锚点与唯一原著引文来源**。

1. **逐字归属**：卡片、框架、正文与任何附属说明中出现的每一句《西游记》原文直接引文，都必须在用户提供的那段文字里逐字找到；找不到的直接删除（若用户在 P4 明确要求补充某句紧邻原文，须经核验并纳入本次来源文本后再引用）。
2. **禁止擅自借用紧邻下文当论据**：未经用户点名要求，不得把紧接的下文或他回情节拉进来当论据或提前剧透，更不得拿整回故事替代当前片段解读。
3. **允许极简情境锚定**：开头允许用 1–2 句极简前情点明说话人与大前提（如孙悟空拜在菩提祖师门下求长生），避免让听众云里雾里；这类情境锚定只在稿外核验栏注明属段外背景，不在正文中编造原文外台词。
4. **鼓励由原文词句触发的传统文化干货延展**：当原文出现道家、佛学、儒家、历法、名物、制度关键词时，外部材料可以将其背后的文化知识讲深讲透，前提是**起点从原文已出现的词句生发，终点收回到原文的人物、叙事或核心追问**，不借外部材料偷渡原文外《西游记》剧情。
5. **候选点硬筛**：候选点的锚点必须是用户原文里的字；脱离当前文本、完全依赖后文情节才能成立的角度，不进候选卡。

## 二、原文核验与版本纪律

1. **来源区分与防记忆点名**：区分百回本原著、电视剧台词、白话改写、错引和二手转述。出处判断只引用本次文字里看得见的特征；**回目归属、人物前情若不在本次文字内，一律显式写为“段外推测，依据不在本次文字内”**。**未实际翻检纸本页码前，严禁凭记忆点名“金陵世德堂本”“人民文学出版社整理本”等具体版本称高度一致，也严禁凭记忆把通行印象写成确定异文。**
2. **能核验**：说明出处和采用的文本版本；用户提供的文字优先作为本次分析对象。指定版本能够核验时，异文判断必须绑定“版本、可追溯位置、具体字句”，不能只用“通行本通常作”替代指定底本核验；若核验材料同时登记书内页与 PDF/扫描页，在核验说明中并列写出。
3. **只能部分核验**：明确哪些字句待核，仍可对用户给出的文字做文本分析，但不得把版本判断说满。未实际核验指定版本时，只能写“该文本与当前可核验文本不同”，不得断言“该版原文不是……”。
4. **额外异文**：发现核心任务之外的额外异文，有可追溯证据才纳入；否则标记待核，不把记忆或通行印象写成确定异文。
5. **硬停条件（`HARD_STOP`）**：原文无法确认且核心论证依赖异文时，立即停止，先向用户请求出处或允许采用的底本版本。
6. **严禁凭记忆补写原文**：在线搜索、摘要和 OCR 只作定位线索；直接引文必须来自可核验文本或明确标为用户提供的文字。

## 三、机械引文核验协议（`QUOTE_FIDELITY`）

### 1. 适用范围（全交付物覆盖）

本节规则适用于本 Skill 产出的**任何文本**，不限成稿：路由说明、候选卡、框架、口播正文、文章正文、三审记录、研究说明、拒答或澄清消息同样逐条适用。

用户消息中的原话与《西游记》原文同等受保护：引用须逐字含标点，截取按节引规则标省略号，不复述时不加引号。

### 2. 逐字与节引判定标准

- **逐字保真**：所有直接引文必须与来源逐字一致——不增字、不减字、不换字、不调整词序。
- **引语与句读单位定义**：
  - **引语**：来源中对白或引号内的整段文字；
  - **句读单位**：以句号（`。`）、问号（`？`）、叹号（`！`）、分号（`；`）或引号界定的整句。
- **节引规则**：取自同一条引语或同一个句读单位内部而截去首尾或中间字句的，不论截去的是中间还是两端，都算节引；**被截断的每一端都必须标省略号（`……`）**，省略号之外的字一个不动。
- **两种豁免情形**：
  1. **短词/短语豁免**：去掉标点后不足 8 个字，且本身不含 `，。！？：；、` 的短词/短语，不算节引，不必加省略号；
  2. **纯标点截断豁免**：截断处只剩标点（例如只少了来源句末的句号）的，不算截断，不必加省略号。

### 3. 引号禁用区（防伪引文）

除逐字引用原文或用户原话外，**任何文字不得置入任何成对引号**（包括 `“…”`、`‘…’`、`「…」`、`『…』` 和英文直引号 `"..."`）：

- 不得包裹自己的概括、压缩或概念标签；
- 不得包裹自己写的章节/小节标题、表头、断言等级标签或清单项名称；
- 输入之外的回目、篇名、书名不得用引号包裹（书名用书名号 `《》`）；
- 照抄规范里的示例句式时也不加引号。

### 4. 机械核验动作（不以自述替代证据）

交付前必须优先执行确定性脚本验证：

```bash
python3 scripts/verify_draft.py --source <原文文件> --draft <交付稿文件>
```

若运行环境无 shell，则执行人工机械扫描：逐处抄出全文所有成对引号内的文本及所在行，与用户原文逐字符比对（节引只比对省略号以外各段，且核对截断端省略号）；未命中项属于自己措辞的立即去引号，误引的立即改正或删除，再复扫一遍直到零未命中。

**严禁用“我逐字抄的”“引文可核”这类自述代替核验动作**——自述不构成证据，机械核验输出才构成证据。

## 四、字义分辨与解读边界（含防现代化误读）

1. **近义词/古词字义分辨**：分辨两个近义词的字义或用法时，要么给出可核验的字书或校注依据，要么明确标为推测；只凭语感的字义区分不得写成“语言证据”或“文本事实”。
2. **边界逐项绑定锚点**：逐项写出本片段最容易被过度解释的地方（不挑单处敷衍），每一处都绑定一个具体原文锚点（字词、动作、称谓或顺序），并说明为何暂不把话说满。
3. **正文可辨认与禁止型边界就地化解（反规则穿帮）**：
   - 边界必须在正文**相关段落**自然显露，**就地插在刚讲到该人物或字句的位置顺嘴拦住**（1–2 句聊天口吻），绝不攒到篇末集中批发成工整的“一种……另一种……”避坑免责专区；只写在稿外边界栏、正文看不到的不算覆盖，正文更不得一边设边界一边越界。
   - 凡属禁止型边界（不把人物言行代入现代观念、不把局部说法推为社会史定论、不把片段判断扩为全书定论等），除在边界栏立条外，正文相关段落必须点名诱惑读法并就地拒绝，用陈述式表达，不用否定对照句式。
   - **用“不写”本身守住范围锁**：切勿在正文里向听众宣读“原文没写 XX、咱不翻片段外的账”，这既出戏又容易顺嘴带出原文外情节；范围约束只在稿外边界栏交代即可。
   - **严禁泄露内部评审/辞书术语**：口播正文中不得出现“朴素解释”“再校一遍”“范围锁”“两种现代读法”“按近代汉语用法”等 SOP 穿帮词；把词义、反检和边界全部化作真人聊天的自然口语。
4. **人物与文本边界宁缺毋滥（绝不造稻草人）**：对片段中有言行亮点的角色或高争议词句，检查当代读者**真正自然会滑进去的 1–2 个高概率误读**（如民主选举、职场博弈、旁门=邪门等）并在对应段落顺势用陈述式点破；写景或意象段无须为了凑数硬造生僻现代标签（如“基因代码造物”），且多处边界必须换用不同口语方式化入，严禁连续套用同一句“回到字面上看，其实……”。
