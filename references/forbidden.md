# 禁忌词 / 规则清单

> 审核成稿（P6 一审及 A 模式自检）时逐条检查，并与 `scripts/verify_draft.py` 机械校验联动。分为硬规则（超限直接修正）和软规则（标出供判断）。
> 用户可随时要求增删改。

## 硬规则（触发即修正）

以下统计均针对**正文本体**，且**扣除直接引用原文里的字词与标点**（不误伤《西游记》原著本身）。

### 1. 禁用词汇 / 短语（0 容忍，出现即删改）

| 禁用表达 | 替换建议 |
|---|---|
| 最让我停下来想的一章 | 删除，直接进内容 |
| 这话听着软，其实很硬 | 删除，直接讲道理 |
| 有没有过这样的时刻？ | 删除，换直入式钩子 |
| 读到……一句话，愣住了 | 改为有句话很喜欢等自然感受带出，或直接讲文本 |
| 里面藏着…… | 改为直接陈述 |
| 这里值得停一下…… | 删除，直接展开 |
| 这句话让我想了好久…… | 删除，直接讲 |
| ……没变，……没变，变的是…… | 改为递进式或直接陈述 |

### 2. 限频句式与标点规则

- **否定对照句式**（不是……而是……、不是……，是……、不在……而在……、不在于……而在于……、不仅……更……、并非……而是……）：**每千字 0–1 处**（以正文本体去引文后的汉字数为分母；1000–1200 字口播稿全篇**最多 1 处**，能用递进式或直接陈述就优先不用；超标即改写）。
  - 特别说明：正文点破禁止型边界或现代化误读时，优先用陈述式，不占用这 1 处额度。
- **但 / 但是**：**每千字最多 1 处**（千字短稿最多 1 处）。超出部分用不过、然而、却替代，或直接删去。
- **破折号（——）**：全篇正文最多 **2 个**。多用逗号、句号断开。
- **冒号（：）**：全篇正文最多 **3 个**。多用句号断句更口语。
- **感叹号（！）**：全篇正文最多 **1 个**（扣除直接引文内的原著叹号）。

## 软规则（标出供判断或局部润色）

以下规则需要结合语境判断，审核时标出位置和修改建议：

- **结尾多样性**：对照 `history.md` 最近 2 篇，检查是否使用了相同的收束方式。如重复，标出并换一种。
- **过渡句多样性**：检查认领旧认知的过渡句（如这个……太正常了）是否与近期重复，每篇换一种。
- **开头多样性**：对照 `history.md` 最近 2 篇，检查钩子切入方式是否重复。
- **说理段落人称**：说理时优先用我们而非指教式的你应该、你要（代入场景的画面句除外，如你是官宦子弟、你得敢跳进去）。
- **整体 AI 味**：通读全文，若语感过于工整、缺乏讲述者立场、转折过于顺滑，标出并注入更真实的口语停顿与判断。
