# 禁忌词 / 规则清单

> 审核口播稿时逐条检查。分为硬规则（自动修正）和软规则（标出供用户判断）。
> 用户可随时要求增删改。

## 硬规则（自动修正）

以下词汇 / 句式一旦出现，直接替换或删除：

### 禁用词汇 / 短语

| 禁用 | 替换建议 |
|------|---------|
| "最让我停下来想的一章" | 删除，直接进内容 |
| "这话听着软，其实很硬" | 删除，直接讲道理 |
| "有没有过这样的时刻？" | 删除，换直入式开头 |
| "读到XX里一句话，愣住了" | 改为"有句话，很喜欢"等个人感受带出 |
| "里面藏着……" | 改为直接陈述 |
| "这里值得停一下……" | 删除，直接展开 |
| "这句话让我想了好久……" | 删除，直接讲 |
| "XX 没变……，XX 没变……，变的是 XXX……" | 改为递进式表达 |
| "不是……而是……" | 改为递进式："……，更进一步说，……" |
| "不是……是……" | 同上 |
| "不在于……而在于……" | 同上 |

### 禁用句式规则

- **"但 / 但是"**：每 1000 字最多 1 个。超出部分用"不过""然而""却"替代，或直接去掉。
- **破折号**：每篇最多 2 个。多用逗号、句号断开。
- **冒号**：每篇最多 3 个。多用句号断句。
- **感叹号**：每篇最多 1 个。

## 软规则（标出供用户判断）

以下规则需要主观判断，审核时标出位置和建议，由用户决定是否修改：

- **结尾多样性**：检查是否与最近 2 篇（参照 history.md）使用了相同的结尾句式。如重复，标出并建议换一种。
- **过渡句多样性**：检查"认领旧认知"的过渡句（如"这个XX太正常了"）是否与近期重复。每篇应换一种方式。
- **开头多样性**：检查是否与最近 2 篇使用了相同的开头模式。
- **说理段落人称**：检查是否用"我们"而非"你"。如出现"你应该……""你要……"等指教式表达，标出。
- **整体 AI 味**：通读全文，如发现整体语感偏"AI 生成"（过于工整、缺乏个人色彩、转折太顺滑），标出并建议注入更多口语感和个人判断。
