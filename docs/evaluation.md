# Skill 回归测试与验收规范（维护者手册）

> 本文件供 Skill 维护者在修改 `SKILL.md`、`references/` 或 `scripts/` 后执行回归验收时查阅，运行时不占用 Agent 上下文。
> 本地回归战役日志与私密观察账本继续保留在 `.gitignore`（如 `references/regression-*`、`references/release-observation-log.md`），本文件提供公开、可复现的评分维度、硬门槛与红线标准。

## 一、最小回归套件

每次修改 Skill 规则后，至少运行以下测试集：

1. **结构对照样例（至少 2 篇）**：
   - 一篇以**动作 / 叙事结构**为主（如石猴跳水帘洞、猴王出世等）；
   - 一篇以**人物对话 / 关系张力**为主（如唐僧推责、师徒争辩等）。
2. **正式发版扩展验收**：
   - **未见文本（Unseen）**：至少 2 段不在 `examples/` 中的真实《西游记》原文片段；
   - **负向与安全输入**：86 版电视剧台词 / 错引改写文本 / 要求把片段硬扩成全回 / 要求直接跳过核验；
   - **路由与关口测试**：分别验证默认管线 P（是否老实停在 P2 与 P4、P2 是否零推荐）、直出模式 A、仅候选卡 B、已指定角度（是否仍做 P0 再进 P3）、完整回目长文转交 `xiyouji-chapter-longform`；
   - **重复运行与独立盲审**：盲审者不得看到历史分数、预设结论或生成稿自带的三审结论；普通数值回归、路由测试、兼容性输入和安全探针分账记录，不用一个总平均数掩盖类别失败。
3. **测试隔离原则**：不得用同一份输出同时充当测试输入和验收标准。

## 二、机械门先行（0 容忍预检）

在进入人工/盲审打分前，必须先通过确定性校验脚本：

```bash
python3 scripts/verify_draft.py --source <原文文件> --draft <交付稿文件> --genre spoken --min-hanzi 1000 --max-hanzi 1200
```

任一机械硬项失败（退出码非 0），直接判本轮回归不通过，无需进入主观测评。

## 三、公开评分 Rubric（总分 100 分，≥ 90 分且零红线通过）

| 维度 | 满分 | 评分标准 |
|---|---:|---|
| 1. 范围锁与引文保真（`SCOPE_CONTROL` / `QUOTE_FIDELITY`） | 20 | 零原文外情节借用；每处直接引文逐字命中用户原文；节引规范；非原文绝不加引号 |
| 2. 文本细读与主轴推进（`TEXT_COVERAGE` / `ANCHOR_CLOSURE` / `PROGRESSION`） | 20 | 每个逻辑单元有实质发现并锚定具体字词/动作/顺序；相邻段落层层推进不原地换词重复 |
| 3. 证据校准与反向检验（`EVIDENCE_CALIBRATION` / `COUNTERCHECK` / `RESEARCH_RELEVANCE`） | 15 | 事实/背景/解读/推测分层清晰；至少一处关键判断经朴素/替代解释检验；无凑数外部材料 |
| 4. 边界与现代化误读点破（`COVERAGE_POINTS` + 边界规则） | 15 | 稿外逐项立边界并绑定锚点；人物言行必查现代化误读；禁止型边界在正文用陈述式自然点破；任务要求覆盖点无并句带过 |
| 5. 口播语感、立场与节奏（`VOICE`） | 15 | 像有判断的真人在公共讲座聊天；有鲜明立场与生活画面；无三段式与机械枚举；段落长短有差 |
| 6. 反 AI 味与硬规则遵从（`ANTI_TEMPLATE` + 长度/标点） | 15 | 字数落入目标区间（P 模式 1000–1200 汉字）；否定对照 ≤ 1 处/千字；无禁用短语与 AI 腔；口播钩子/开场白/结束语合规 |

## 四、硬门槛与一票否决红线

触发以下**任意一条**，无论总分高低，本轮一律判 **FAIL**（保留失败输出，先修规则再重跑）：

- **红线 1（伪引文 / 越界引文）**：任意一处引号内容在用户原文中找不到，或引用了紧邻上下文/后文当论据；
- **红线 2（凭空补原文 / 虚假核验）**：未核验版本却断言“某版原文不是……”，或用“我逐字抄的”代替机械校验；
- **红线 3（跳过人工关口 / 违规推荐）**：管线模式 P 跳过 P2 或 P4 等待点，或在 P2 替用户排序/推荐角度；
- **红线 4（字数硬超限）**：管线模式 P 正文本体汉字数超出 1000–1200（未经 P4 明确批准例外）；
- **红线 5（边界空转）**：稿外写了禁止型边界或存在明显现代化误读人物，但正文中未点破，或一边设边界一边越界；
- **红线 6（机械硬规则超标）**：出现 `forbidden.md` 零容忍禁用短语，或否定对照句式 / `但` 字 / 破折号 / 冒号 / 感叹号超限。

## 五、棘轮保留原则（参考达尔文 / 鲁班回炉纪律）

1. 改动前先保留当前基线分数与样例输出；
2. 每次改动优先聚焦单一根因，跑通 `scripts/test_verify_draft.py` + 最小回归套件；
3. 仅当新版本在红线清零、总分不降且目标痛点明显改善时保留提交；出现任意维度明显回退时，先回溯根因再局部重修，不靠堆砌冗长补丁覆盖旧规则。
